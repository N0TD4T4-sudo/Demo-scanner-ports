# Scanner-ports-my-pc
## Que hace el programa?
    analiza los puertos abiertos en la direccion 127.0.0.1 (el equipo propio) dentro de un rango de puertos el cual usted ingresará , al final devuelverá Los puertos abiertos encontrados.
## Como se usa? 
    El script se ejecuta con el comando python .\scanner.py (Windows) y introduciremos el rango en el cual queremos que escanee. El script tiene un limite del puertos 1 hasta el 65535
## Que se necesita?
    * Python 3 (incluye socket y time por defecto)
